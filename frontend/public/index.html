🛡️ Arhitektura & Observability

Ovaj alat je SRE (Site Reliability Engineering) portfolio projekt. Izgrađen je na modernoj arhitekturi koristeći FastAPI, PostgreSQL, i Docker uz striktne Zero-Trust sigurnosne protokole preko Cloudflare Tunnels-a.

⚙️ Prometheus & Loki

Pravi Site Reliability Engineering se ne oslanja na nagađanje. Ovaj sistem koristi Prometheus za prikupljanje time-series metrika, prateći zdravlje API-ja i brzinu scrapinga u milisekundama.
Paralelno, Python mikroservisi emituju strukturirane JSON logove koje Grafana Alloy presreće direktno sa Docker socketa i prosljeđuje u Loki.
Onda, napredni LogQL pristup omogućava trenutnu detekciju anomalija u radu sistema, okidajući Telegram alarme čim lokalne elektrodistribucije promijene strukturu svojih web stranica – sve bez potrebe za ručnim debugom kao što je npr. SSH pristup serveru.
